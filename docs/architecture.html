Minutama Architecture

The whole system on one page: the Windows app, the Supabase server, outside services (OpenAI, Stripe, Resend) and the minutama.com website. AI keys live only on the server. Audio and notes stay on the user's computer.

App on the PC Our server Outside services Website and delivery Live audio, direct
  • 1The app calls server functions over HTTPS with the user's token. The app holds no AI keys.
  • 2Live audio goes straight to OpenAI Realtime over WebSocket. live-session issues a temporary 120 s key.
  • 3Functions call OpenAI: translation, question cards, notes, reports.
  • 4Functions create Stripe checkout and portal sessions. Stripe calls the webhook, and only the webhook turns a plan on.
  • 5Functions read and write plans, limits and events in Postgres.
  • 6Auth sends emails through Resend SMTP.
  • 7The app asks the website for the user's country and shows that region's price.
  • 8The app checks latest.yml on GitHub and installs the new version itself.
  • 9The website runs behind Cloudflare: proxy, visitor country, analytics.

What happens during a call

1. AudioThe mic ("Me") and system audio ("Them") are recorded separately.
2. LiveTranscriberAudio is resampled to 24 kHz. Silence is cut and never sent.
3. OpenAI RealtimeRecognizes words in the language set in Settings.0.2–0.4 s
4. FiltersDrop unexpected scripts (e.g. Chinese) and the client's echo in the mic.
5. translate-lineStreams a translation of the client's lines while they are still speaking.~0.45 s to first words
6. CapsuleCaptions type out with an orange leading edge, the translation is indented, scrolling is automatic.
In parallel: question cardsWhen the client finishes a question, suggest-reply shows a card: question, translation, term and hint.~2 s
After the callenhance-notes writes notes, a client brief, an estimate and a follow-up email. Everything is saved in SQLite on the PC.
Recording for historytranscribe-chunk counts minutes for the limits. Audio is deleted on the server right after processing.
