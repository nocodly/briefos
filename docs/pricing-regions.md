# Регіональні ціни і перші регіони для тесту

Ціни підставляються автоматично за країною (Cloudflare визначає країну відвідувача).
Години й функції однакові всюди. Код: `supabase/functions/_shared/regions.ts` і `web/lib/regions.ts` (тримати однаковими).

## Чи окупається (оцінка)

- Наша собівартість години дзвінка: ~$0.40 (розшифровка двох каналів + AI).
- Комісія Stripe з $5: ~$0.55, тож чисті ~$4.45.
- Рівень 4 у плюсі, поки людина використовує до ~11 годин на місяць із 25. Більшість фрилансерів має 4–8 годин дзвінків на місяць.
- Якщо в якомусь регіоні люди масово вибирають усі 25 годин, зменшимо години або піднімемо ціну для цього рівня.

## Як порівнювати

Через тиждень у Supabase → SQL editor запустити `supabase/queries/funnel.sql` і порівняти по регіонах:
відвідування (Cloudflare Web Analytics) → завантаження → реєстрація → перший дзвінок → відкрили оплату → оплатили.
Регіон з найкращою ціною за платного клієнта отримує весь бюджет.
